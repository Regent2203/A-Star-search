# A* Search Algorithm

An interactive, real-time visualization of the **A* (A-Star) search algorithm** implemented in Unity. This project demonstrates pathfinding capabilities across multiple environment configurations and grid types.

## 🚀 Key Features

* **Multiple Grid Configurations:** Supports **Square grids**, **Hexagonal grids**, and **Continuous space** (gridless fields).
* **12 Pre-made Scenes:** Explore different test environments and layout complexities right out of the box.
* **Real-Time Map Editing:** Modify any field dynamically. The algorithm automatically recalculates and updates the path with every change.
* **Save & Load System:** Save your custom field configurations and reload them later using the built-in **JSON format** support.
